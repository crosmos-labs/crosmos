## Quickstart

Get Crosmos running locally.

<Steps>
<Step title="Install the CLI">

```bash
npm i -g mint
```
</Step>

<Step title="Preview locally">

```bash
mint dev
```

Open `http://localhost:3000`.

</Step>
</Steps>
